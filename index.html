📘 មេរៀន CSS Grid & លំហាត់អនុវត្ត (CSS Grid Instructor)

១. ការពន្យល់ Page Grid (grid-template-areas)

នៅលើ Desktop យើងប្រើប្រាស់ grid-template-columns: 240px minmax(0, 1fr) ដើម្បីកំណត់ Sidebar ទទឹង 240px ថេរ និង Main Content ពង្រីកបត់បែនតាមផ្ទៃអេក្រង់។ តាមរយៈ grid-template-areas យើងផ្គុំប្លង់ទំព័រយ៉ាងច្បាស់លាស់៖ 

.site-layout {
  display: grid;
  grid-template-columns: 240px minmax(0, 1fr);
  grid-template-rows: auto 1fr auto;
  grid-template-areas:
    "header  header"
    "sidebar main"
    "footer  footer";
}

/* លើ Mobile (max-width: 880px): ប្ដូរទៅ 1 column */
@media (max-width: 880px) {
  .site-layout {
    grid-template-columns: 1fr;
    grid-template-areas:
      "header"
      "sidebar"
      "main"
      "footer";
  }
}

ហេតុអ្វីប្រើ minmax(0, 1fr) ជំនួស 1fr សុទ្ធ?
ដោយសារនៅក្នុង CSS Grid ទំហំដើម (min-content) របស់ grid item គឺ auto។ ប្រសិនបើយើងប្រើត្រឹម 1fr ពេលមានរូបភាព ឬអក្សរវែងខ្លាំង Main អាចរីកលើសទទឹងបង្ក horizontal scrollbar។ ការដាក់ minmax(0, 1fr) បង្ខំឱ្យ min-width ចាប់ផ្ដើមពី 0 ធានាគ្មានការរុញអេក្រង់។

២. ការពន្យល់ Product Grid & Nested Card Grid

យើងប្រើប្រាស់រូបមន្តទំនើបបំផុតរបស់ CSS Grid សម្រាប់ Product Listing៖ 

.product-grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(min(100%, 220px), 1fr));
  gap: 24px;
}

វិភាគកូដ៖
• repeat(auto-fit, ...)៖ បង្កើតចំនួន Column ដោយស្វ័យប្រវត្តិតាមទទឹងអេក្រង់។ បើអេក្រង់ធំ មាន column ច្រើន, បើអេក្រង់តូច វានឹងទម្លាក់ចុះក្រោមដោយមិនបាច់សរសេរ media query ច្រើនជាន់។
• min(100%, 220px)៖ ការពារបញ្ហាអេក្រង់ទូរស័ព្ទតូចជាង 220px (ឧទាហរណ៍អេក្រង់ចាស់ៗ)។ វានឹងយក 100% ប្រសិនបើទំហំតូចជាង 220px。
• Nested Grid នៅក្នុង Card៖ កាតផលិតផលនីមួយៗប្រើ display: grid; grid-template-rows: 180px auto 1fr auto auto; ធ្វើឱ្យរូបភាព, ចំណងជើង, តម្លៃ និងប៊ូតុងតម្រង់ជួរត្រង់ស្មើគ្នាគ្រប់កាតទាំងអស់ ទោះបីជាចំណងជើងមានប្រវែងខ្លីឬវែងខុសគ្នាក៏ដោយ!

៣. លំហាត់អនុវត្ត ៣ (CSS Grid Exercises)

លំហាត់ទី ១៖ បន្ថែម Banner ពិសេសតាមរយៈ Grid Area

កិច្ចការ៖ កែសម្រួល grid-template-areas នៅក្នុង .site-layout ដោយបន្ថែម Area ថ្មីឈ្មោះថា "banner" នៅចន្លោះ Header និង Sidebar/Main។ បង្កើត HTML <div class="promo-banner"> និងកំណត់ grid-area: banner; ដើម្បីបង្ហាញការបញ្ចុះតម្លៃពិសេស។

លំហាត់ទី ២៖ សាកល្បង auto-fill ប្រៀបធៀបជាមួយ auto-fit

កិច្ចការ៖ ផ្លាស់ប្ដូរ repeat(auto-fit, ...) ទៅជា repeat(auto-fill, ...) នៅក្នុង .product-grid។ បន្ទាប់មកសាកល្បង Filter រើសប្រភេទដែលមានផលិតផលតែ ២។ តើអ្នកសង្កេតឃើញភាពខុសគ្នាយ៉ាងណាលើទំហំ Card? (គន្លឹះ៖ auto-fit នឹងពង្រីក Card ឱ្យពេញផ្ទៃ, រីឯ auto-fill រក្សាទំហំជួរឈរទទេ)។

លំហាត់ទី ៣៖ បង្កើត Badge "NEW" ដោយប្រើ Grid Line Positioning

កិច្ចការ៖ នៅក្នុង .product-card ជំនួសការប្រើ position: absolute ដោយបង្កើត Grid Row/Column ជាន់គ្នា (Grid Item Stacking) សម្រាប់ Image និង Badge តាមរយៈ grid-row: 1; grid-column: 1; និងប្រើ align-self: start; justify-self: start;។
